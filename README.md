# password_stenth_checker

Password Strength Checker

A simple Python project that checks whether a password is Weak, Medium, or Strong based on security rules.

Features
Checks password length
Detects uppercase letters
Detects numbers
Detects special characters
Gives suggestions to improve password strength
Technologies Used
Python
Regular Expressions (re module)
Project Structure
password-checker/
│
├── main.py
└── README.md

Example:
Enter password: hello123

❌ Add an uppercase letter
❌ Add a special character
❌ Weak Password
Password Rules

A strong password should contain:

Minimum 8 characters
At least 1 uppercase letter
At least 1 number
At least 1 special character
